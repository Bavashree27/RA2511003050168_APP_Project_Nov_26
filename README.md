# 💊 Medicine Reminder

A simple and user-friendly **Medicine Reminder** application designed to help users remember their medicines on time. The project allows users to add medicine details, set reminder times, and keep track of their medication schedule.

## 📌 Features

- ➕ Add medicine details
- ⏰ Set medicine reminder times
- 💊 Store medicine name and dosage
- 📅 Manage daily medicine schedules
- 🔔 Get reminders at the scheduled time
- ✏️ Edit existing medicine details
- 🗑️ Delete medicines
- 📋 View all scheduled medicines
- ✅ Mark medicines as taken

## 🎯 Objective

The main objective of this project is to provide a simple digital solution for managing medication schedules and reducing the chances of forgetting medicines.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Frontend:** HTML / CSS *(if applicable)*
- **Database:** SQLite *(if applicable)*
- **Development Environment:** Visual Studio Code
- **Version Control:** Git & GitHub

## ⚙️ How It Works

1. Open the Medicine Reminder application.
2. Enter the medicine name.
3. Enter the required dosage.
4. Select the date and reminder time.
5. Save the medicine details.
6. The application reminds the user when it is time to take the medicine.
7. The user can mark the medicine as **Taken** after consuming it.

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/medicine-reminder.git
```

### 2. Open the project folder

```bash
cd medicine-reminder
```

### 3. Install required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```
